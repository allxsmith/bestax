# Security Policy

This repository holds the `bestax` plugin. It is generated from
[allxsmith/bestax](https://github.com/allxsmith/bestax) and never edited by
hand, and its issues are turned off.

## Reporting a vulnerability

Please report a vulnerability in the plugin, its skills or the bestax-mcp
server privately, and don't disclose it publicly until it is fixed:

- Email [security@bestax.io](mailto:security@bestax.io).
- Or choose **Report a vulnerability** on the
  [Security tab of allxsmith/bestax](https://github.com/allxsmith/bestax/security).

## Supported versions

Only the latest version is supported. The plugin installs from this
repository's `main`, which is regenerated after every change to the plugin and
every bestax-mcp release.

The full policy, including how reports are handled and the supply-chain
controls behind every bestax package, is in the
[security policy of allxsmith/bestax](https://github.com/allxsmith/bestax/blob/main/SECURITY.md).
