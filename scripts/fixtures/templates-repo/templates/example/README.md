# Example Template, rebuilt with bestax

A test fixture shaped like a real template, for `scripts/templates.test.mjs`.

The original is
[bulma-example-template](https://github.com/example/bulma-example-template) by
Example Author, ported from commit
[`0123456789abcdef0123456789abcdef01234567`](https://github.com/example/bulma-example-template/tree/0123456789abcdef0123456789abcdef01234567).
It's one of the free Bulma templates in aldi's
[awesome-bulma-templates](https://github.com/aldi/awesome-bulma-templates).

## Run it

```bash
npm install
npm run dev
```

In a clone of the bestax monorepo, `pnpm install --ignore-workspace` works too.
